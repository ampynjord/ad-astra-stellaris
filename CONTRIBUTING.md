# Contributing to Ad Astra

Thank you for helping improve Ad Astra. Player reports are as valuable as code contributions.

## Report a bug

Use the [bug report form](https://github.com/ampynjord/ad-astra-stellaris/issues/new/choose). A useful report includes:

- the Ad Astra version and Stellaris version;
- starting age, ascent pace, and in-game date;
- whether this is a new game created after the update;
- the complete load order;
- the unedited `Documents/Paradox Interactive/Stellaris/logs/error.log` after reproducing the issue;
- clear reproduction steps, plus a save file or screenshot when possible.

Please search existing issues first. Do not post tokens, account data, or other private information.

## Suggest an idea

Use the idea form or the Discord ideas forum. Explain the play moment that prompted the idea and the problem it would solve; a finished technical solution is not required. Suggestions are discussed publicly and are not a promise of inclusion.

## Contribute code or localization

1. Open an issue first for changes beyond a small, obvious fix.
2. Branch from the active development branch, not from `main`.
3. Keep one focused concern per pull request and explain its player-facing effect.
4. Do not edit files marked as generated. Change their source data or generator, then regenerate them.
5. Keep public repository documentation and GitHub issue fields in English. In-game localization remains English and French.
6. Code comments are written in French without accents, dated, and explain why a decision exists.

Before opening a pull request, run the project checks requested by the active branch documentation. For normal development this includes generated-file verification, gameplay verification, release verification, and a local build. Include the exact commands and results in the pull request description.

## Community conduct

Be specific, respectful, and assume good faith. Preserve player reports and discussion: only maintainers may edit the project’s fixed editorial Discord messages.
