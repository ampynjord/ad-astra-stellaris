		# --- Le verrou de passage d'age ---
		# On ne quitte pas un age tant qu'il reste quelque chose a y inventer.
		# La barre monte normalement pendant toute l'etape, puis se fige a un
		# point de la fin tant que les dix technos de l'age ne sont pas toutes
		# terminees.
		#
		# UN BLOC PAR TECHNOLOGIE, et non un par age. Le 16/08 : « l'ideal
		# serait d'indiquer dans la situation les technologies manquantes ».
		# Le moteur affiche la ligne desc de CHAQUE modificateur qui s'applique :
		# en declarant une entree par techno, l'infobulle de la barre devient la
		# liste exacte de ce qui reste a trouver, et elle se raccourcit a chaque
		# decouverte. Les multiplicateurs se composent - 0,001 puissance N reste
		# un arret.
		#
		# mult = 0.001 et non 0 : le jeu de base n'ecrit JAMAIS « mult = 0 » dans
		# un monthly_progress, et rien ne garantit qu'un zero y soit lu comme un
		# multiplicateur plutot que comme une valeur absente. A un millieme, il
		# faudrait douze mille ans pour gagner un point : c'est un arret, sans le
		# risque qu'une soustraction ferait courir - une progression negative
		# renverrait le joueur en arriere d'un age.
		#
		# Les etapes du programme spatial n'ont pas de verrou : elles ne sont
		# plus commandees par la recherche mais par les decisions.
