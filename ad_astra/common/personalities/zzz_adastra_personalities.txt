# Ad Astra 1.2 - personnalites d'IA pour les empires confines.
#
# POURQUOI CE FICHIER
#   Les 30 personnalites du jeu de base commencent toutes par
#   « allow = { is_country_type = default } ». Un empire Ad Astra passe en
#   adastra_grounded au premier jour : le moteur ne trouve donc AUCUNE
#   personnalite valide et ecrit dans error.log
#       Failed to choose personality type for <empire> with country type adastra_grounded
#   Tant que l'origine etait reservee au joueur, c'etait du bruit sans effet.
#   Depuis la 1.2 l'IA peut prendre l'origine : sans personnalite, elle n'a plus
#   ni diplomatie, ni arbitrage militaire, ni budget de colonisation.
#
# LE CHOIX D'IMPLEMENTATION
#   On aurait pu surcharger les 30 personnalites du jeu de base pour y ajouter
#   notre type de pays. C'est 30 blocs recopies, donc un conflit garanti avec
#   tout mod qui touche au comportement de l'IA. On declare a la place nos
#   propres personnalites, valables uniquement pendant le confinement : aucun
#   fichier du jeu de base n'est touche.
#
#   A l'emergence, set_country_type = default fait rechoisir une personnalite au
#   moteur (c'est ce meme mecanisme qui produisait l'erreur ci-dessus) : l'empire
#   recupere alors une personnalite normale, coherente avec son ethique.
#
# LES VALEURS
#   Une civilisation enfermee sur son monde natal n'a pas de flotte, pas de
#   colonies, pas de voisins joignables. L'essentiel de ces reglages ne sert
#   qu'a exister ; ce qui compte vraiment est military_spending (elle doit
#   pouvoir se defendre, la guerre est possible dans les deux sens depuis 1.2)
#   et l'acceptation diplomatique (elle a tout interet a signer des accords).

		}
	}

	}
