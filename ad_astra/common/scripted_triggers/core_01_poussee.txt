# Ad Astra - l'echelle de propulsion.
#
# La 1.3 gardait chaque programme spatial derriere sa propre technologie
# fondatrice : quatre gardiens sans rapport entre eux, et seize noms a lire
# dans une infobulle. La 1.4 les remplace par une echelle a cinq rangs.
#
# Le joueur ne se demande plus « ai-je la bonne fondatrice » mais « jusqu'ou
# ma poussee me porte-t-elle ». C'est une seule question, et elle a une
# reponse visible.
#
#   rang 1  suborbital     -> les premiers lancements, et leurs echecs
#   rang 2  orbital        -> satellites, vol habite, station orbitale basse
#   rang 3  interplanetaire-> le premier corps, le vaisseau scientifique
#   rang 4  soutenu        -> le chantier orbital, la flotte
#   rang 5  supraluminique -> la percee
#
# Les seize technologies fondatrices du jeu de base restent a chercher. Elles
# cessent seulement d'etre la grammaire du programme.
#
# LE RANG 4 N'A PAS DE TECHNOLOGIE A LUI, ET C'EST VOLONTAIRE.
#
# Il fallait une « propulsion soutenue » entre l'ionique (1964) et
# l'hyperpropulsion. Deux façons de l'obtenir : inventer une technologie de
# plus, ou reconnaitre qu'un programme spatial mur n'est pas UNE invention
# mais la conjonction de plusieurs.
#
# La premiere coutait une technologie d'epoque : l'Age spatial est plein a
# vingt-cinq, il aurait fallu en supprimer une vraie pour loger une invention
# de remplissage. La seconde ne coute rien et dit quelque chose de plus juste.
#
# Le rang 4 est donc l'ionique PLUS le bouclier ablatif PLUS la
# supraconductivite : savoir pousser longtemps, savoir rentrer, savoir porter
# du courant sans perte. C'est la definition d'un programme spatial qui a
# depasse le stade des coups d'eclat.

# Rang 1 - suborbital. La fusee-sonde de 1946 : on quitte le sol, on n'y
# reste pas. C'est le rang ou les lancements peuvent echouer.
core_poussee_1 = {
	OPTIMIZE_MEMORY
	has_technology = tech_adastra_sounding_rocket
}

# Rang 2 - orbital. Les etages multiples de 1957 : ce qui monte peut rester.
core_poussee_2 = {
	OPTIMIZE_MEMORY
	AND = {
		core_poussee_1 = yes
		has_technology = tech_adastra_rocketry
	}
}

# Rang 3 - interplanetaire. La propulsion ionique de 1964 : une poussee
# faible mais qui ne s'arrete jamais. C'est ce qui permet d'aller ailleurs
# qu'en orbite.
core_poussee_3 = {
	OPTIMIZE_MEMORY
	AND = {
		core_poussee_2 = yes
		has_technology = tech_adastra_ion_drive
	}
}

# Rang 4 - poussee soutenue. Pas une invention : un programme mur.
core_poussee_4 = {
	OPTIMIZE_MEMORY
	AND = {
		core_poussee_3 = yes
		has_technology = tech_adastra_heat_shield
		has_technology = tech_adastra_superconductivity
	}
}

# Rang 5 - supraluminique. La percee.
core_poussee_5 = {
	OPTIMIZE_MEMORY
	AND = {
		core_poussee_4 = yes
		has_technology = tech_hyper_drive_1
	}
}

# Forme parametree, pour ecrire `core_poussee_au_moins = { rang = 3 }`.
core_poussee_au_moins = {
	OPTIMIZE_MEMORY
	core_poussee_$rang$ = yes
}
